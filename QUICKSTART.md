# Краткое руководство по запуску

## Быстрый старт

### 1. Установка зависимостей
```powershell
pip install -r requirements.txt
```

### 2. Настройка подключения
```powershell
# Скопируйте пример конфигурации
Copy-Item .env.example .env

# Отредактируйте .env и укажите параметры вашего SQL Server
```

### 3. Запуск приложения
```powershell
python main.py
```

## Основные возможности

### 🔐 Безопасность
1. **Audit** - События безопасности
2. **DDM** - Маскировка данных (Admin vs Cashier)
3. **Extended Events** - Медленные запросы
4. **Backup** - Автоматизация резервного копирования
5. **TDE** - Шифрование базы данных

### 🏗️ Архитектура
6. **Filegroups** - Распределение данных

### 💼 Бизнес-логика
7. **Triggers** - Автоматизация
8. **Procedures** - Операции
9. **Views** - Отчеты
10. **Functions** - Расчеты

## Демонстрация для курсового проекта

### Сценарий 1: DDM (5 минут)
1. Запустите приложение с ролью **Admin**
2. Выберите `2. DDM` → `4. Side-by-Side Comparison`
3. Покажите разницу в отображении данных

### Сценарий 2: TDE (3 минуты)
1. Выберите `5. TDE` → `1. View Database Encryption Status`
2. Покажите статус шифрования
3. Покажите информацию о сертификате

### Сценарий 3: Backup (5 минут)
1. Выберите `4. Backup` → `1. View SQL Agent Jobs Status`
2. Покажите расписание резервного копирования
3. Покажите историю выполнения

### Сценарий 4: Triggers (5 минут)
1. Выберите `7. Triggers` → `1. View All Triggers`
2. Выберите `5. Test Order Audit Log Trigger`
3. Покажите автоматическое логирование

### Сценарий 5: Filegroups (3 минуты)
1. Выберите `6. Filegroups` → `6. View Distribution Summary`
2. Покажите распределение данных по файловым группам

## Роли для тестирования

- **Admin** - Видит все данные без маскировки
- **Manager** - Полный доступ, видит немаскированные данные
- **Cashier** - Видит маскированные данные клиентов
- **Tailor** - Ограниченный доступ, видит маскированные данные

## Типичные проблемы

### "Connection failed"
➜ Проверьте, что SQL Server запущен и БД Atelier существует

### "No module named 'pyodbc'"
➜ Выполните: `pip install -r requirements.txt`

### "Driver not found"
➜ Установите ODBC Driver 17 for SQL Server
